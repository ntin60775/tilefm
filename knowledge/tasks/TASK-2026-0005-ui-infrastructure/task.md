## Описание

Реализовать UI-инфраструктуру: окно настроек и систему справки.

**Настройки (Preferences Dialog):**
- `Ctrl+,` — открыть настройки (или через меню)
- Полноэкранный диалог с вкладками:
  - Общие (подтверждения, поведение)
  - Вид (размер иконок, скрытые файлы, сортировка)
  - Горячие клавиши (таблица action → shortcut, editable)
  - Расширения (список плагинов)
  - О программе

**Справка по горячим клавишам:**
- `Ctrl+H` — открыть overlay/окно со списком всех горячих клавиш
- Кнопка `?` в toolbar → тоже самое

**Общая справка:**
- `F1` — открыть справку (возможно, HTML в WebKit или простой TextView)
- Меню: Справка → О программе
