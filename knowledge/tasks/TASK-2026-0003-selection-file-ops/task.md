## Описание

Реализовать полный набор операций выделения и работы с файлами:

**Selection:**
- `Ctrl+A` — выделить всё в текущей плитке
- `Ctrl+I` — инвертировать выделение
- `Shift+Click` — выделить диапазон (от последнего выделенного до кликнутого)
- `Ctrl+Click` — добавить/убрать из выделения
- `Ctrl+Shift+A` — снять выделение со всех

**Файловые операции:**
- `Ctrl+Shift+C` — копировать путь выбранных файлов в буфер обмена
- `Ctrl+Shift+N` — создать новую папку в текущей директории
- `Shift+Delete` — удалить файлы навсегда (с подтверждением)
- `F2` — переименовать (уже частично есть в контекстном меню, нужна обработка шортката)
