## Описание

Реализовать полноценный drag & drop между плитками как во всех нормальных файловых менеджерах (Thunar, Nemo, Nautilus):

**Базовый D&D:**
- Перетащить файлы из одной плитки в другую → переместить файлы
- При наведении на целевую плитку — показать визуальный индикатор (подсветка drop zone)
- При отпускании — выполнить move операцию

**Модификаторы:**
- `Ctrl+Drag` → копировать файлы вместо перемещения
- `Shift+Drag` → создать symlink вместо перемещения/копирования
- Перетащить папку с `Alt` → скопировать рекурсивно

**Drop на плитку:**
- Если drop на плитку с файлами — открыть эту папку в целевой плитке
- Если drop на конкретный файл — выполнить операцию (move/copy/link)

**Визуальная обратная связь:**
- Drag image (иконки перетаскиваемых файлов)
- Drop indicator (подсветка целевой плитки)
- Progress bar для больших операций
